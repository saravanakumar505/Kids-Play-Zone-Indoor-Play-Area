WonderPlay Template Documentation

Version 1.0.0 • Multipurpose Kids Play Zone & Indoor Play Area HTML Template

1. Introduction

WonderPlay is a clean, modern, and highly modular HTML5/TailwindCSS template built for indoor playgrounds, family entertainment parks, kids activity centers, and birthday venues.

2. Folder Structure

kids-play-zone/
├── index.html              # Home 1 - Indoor Play + Family Experience
├── pages/                  # Public Pages (Home 2, Play Zones, Parties, Safety, Blog, Pricing, Login, Register, etc.)
├── dashboard/              # Dedicated Parent/Customer Dashboard with Multi-child session booking & QR Pass
├── admin/                  # Dedicated Admin Management Dashboard with live charts & zone capacity meters
├── assets/
│   ├── css/                # style.css, dark-mode.css, rtl.css
│   ├── js/                 # theme.js, rtl.js, navigation.js, validation.js, booking.js, dashboard.js, admin.js, main.js
│   └── images/             # Local SVG assets (hero, zones, parties, team, testimonials, blog, gallery, logo)
├── documentation/          # Buyer documentation
└── README.md

3. Color Customization

You can modify primary colors in assets/css/style.css:

:root {
  --primary: #5B3FD3;      /* Deep Purple */
  --secondary: #FF7A45;    /* Tangerine */
  --accent: #FFD84D;       /* Sunshine Yellow */
  --mint: #52D6B5;         /* Mint Green */
  --background: #FFF9F0;   /* Warm Cream */
  --text-main: #252238;    /* Deep Charcoal */
}

4. Features Included

  • Dual Independent Dashboards: Separate Parent/Customer and Admin interfaces
  • Multi-Child Interactive Booking Wizard with real-time price & slot calculations
  • Dark Mode toggle & true bidirectional RTL layout switching
  • Responsive Navigation Drawer with auto-reset upon viewport expansion
  • Accessible forms with instant client-side validation
  • 100% SVG Lucide Icons, zero emojis
  • Self-contained local vector graphics
